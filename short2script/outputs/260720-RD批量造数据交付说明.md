## API 环境配置

RD 在自己的安全目录创建环境文件，不要放入管线包：

```dotenv
base_url=https://<rd-oneapi-host>
ONEAPI_API_KEY=<rd-side-secret>
```

运行前指定该文件：

```bash
export ONEAPI_ENV_FILE=/secure/path/.env-rd-oneapi
```

可选覆盖：

- `ONEAPI_MODEL`：默认 `Claude Opus 4.6`。
- `ONEAPI_MAX_TOKENS`：默认 `128000`。
- `ONEAPI_THINKING_TYPE`：默认 `adaptive`。
- `ONEAPI_EFFORT`：默认 `high`。
- `CURL_MAX_TIME`：默认 `2400`秒。

默认 Opus 脚本会保存每次 attempt 的脱敏响应头、原始响应、HTTP 状态、首 token 时间、总耗时、终止事件和 parser 结果。

## 默认校验口径

`collect` 模式下只有以下问题中断生产：

- API 失败、超时、空输出、流式响应无完整终止事件。
- JSON 解析失败。
- 根字段或嵌套 hard contract 必填字段缺失。
- 08 缺 `final_script`、`state_update` 或 `continuity_update`。
- 目标集数不足、`episode_num` 不连续、artifact 写入失败。

剧作、格式、字数、闪回/OS/VO、地点、出场人物、分场、台词可拍摄性、事件窗口、跨集重复等问题默认进 `warnings`，不中断 5 集或 full run。需要恢复质量硬 gate 时使用 `--strict-validation`。

状态含义：

- `generation_status=PASS`：产物结构完整，无默认生产阻断。
- `quality_status=PASS/WARN`：内容质量是否存在 warning。
- `overall_status=PASS`：在 collect 模式下代表完整产出且可审计，不等于内容已人工验收。
- `overall_status=PARTIAL`：未覆盖全部目标集数，不得当成完整 run。

## 恢复与复用

- `--resume-from <stage_id>`：保留上游，清理该阶段及下游后重跑。
- `--reuse-through <stage_id>`：强制复用至该阶段，重跑下游。
- `--reuse-existing-episodes`：只在 prompt、behavior、runtime 和 ledger input hash 都匹配时复用旧 08 产物。
- `--force-reuse-existing-episodes`：不安全复用，只应用于明确知道风险的调试，管线会记录醒目 warning。
